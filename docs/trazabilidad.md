cubren. Las pruebas marcadas con ★ en §15 son las críticas. La prueba
`tests/unit/test_entrega.py::test_la_trazabilidad_apunta_a_pruebas_que_existen` verifica que todas
las referencias de este documento existan, para que no se desactualice.
